Harp.js?

Harp.js

The static web server with built-in preprocessing. Harp serves Jade, Markdown, EJS, CoffeeScript, Sass, LESS and Stylus as HTML, CSS & JavaScript—no configuration necessary.

How to use

  1. install
1

npm i -g harp
  1. create website
1
2
3

harp init hello-harp
cd hello-harp
harp server
  1. compile
1

harp compile
  1. metadata
  • _data.json
1
2
3
4

"team": {
  "title": "Team page",
  "members": ["Rob", "Brock", "Jorge"]
}
  • ejs or jade

  each member in members
