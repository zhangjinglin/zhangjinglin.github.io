CodeIgniter是所有PHP MVC框架中最简单切轻量的一个，我会用一些列的教程来讲解CodeIgniter的使用。

CodeIgniter 是什么？

CodeIgniter是一个PHP的MVC框架，非常简单。

可以访问CodeIgniter网站查看更进一步的信息，在我写作的时候，CodeIgniter的版本是3.0.4。如果你对英文恐慌的话，CodeIgniter中国是完整的中文网站。网站上的用户手册是你最好的朋友，你有任何问题基本上都可以在上面周到解答。如果实在没有解决问题，你可以Google。

  • 模型 代表你的数据结构。通常来说，模型类将包含帮助你对数据库进行增删改查的方法。
  • 视图 是要展现给用户的信息。一个视图通常就是一个网页，但是在 CodeIgniter 中， 一个视图也可以是一部分页面（例如页头、页尾），它也可以是一个 RSS 页面， 或其他任何类型的页面。
  • 控制器 是模型、视图以及其他任何处理 HTTP 请求所必须的资源之间的中介，并生成网页。

如果你暂时不明白没关系，后面你会逐渐理解MVC到底是什么。

添加方法

做一个测试，将index方法的名字修改为其他，例如test再次访问，会发现出现了错误，只有index方法可以作为默认的方法被访问。

如果我们增加一个方法，

1
2
3
4

public function test()
{
    echo "this is test funtion";
}

在浏览器中访问http://localhost/ci/test会出现错误，那到底怎么访问呢？在welcome.php里面的注释中说明了如何访问：

1
2
3

* 		http://example.com/index.php/welcome
*	- or -
* 		http://example.com/index.php/welcome/index

所以访问test方法的路径是http://localhost/ci/index.php/welcome/test，测试一下。在CI中，index.php是入口文件，所有的访问都通过这个文件进行转发。

如果忽略路径中前面的部分，我们访问的方式就是{控制器/方法}。

class User_model extends CI_Model
{
    public function get_users()
    {
        //通知CI装载数据库组件
        $this->load->database();
        //查询数据库，获取所有users表中的内容
        $query = $this->db->get('users');
        //返回查询结果
        return $query->result();
    } 
}

        $this->load->model('user_model');

        $result = $this->user_model->get_users();

    }
}

自动装载

我们的代码还有些小问题，在每一个模型类的方法中，我们都需要一句代码

1

$this->load->database();

虽说不麻烦，但是总是重复毕竟是不好的。所以我们可以告诉CI把一些在我们应用中总是使用的组件给我们自动装载进来。在config\autoload.php中，修改

1

$autoload['libraries'] = array('database');

然后，在模型代码中，注释掉装载数据库的代码

1
2
3
4
5
6

public function get_users()
{
    //$this->load->database();
    $query = $this->db->get('users');
    return $query->result();
}

重新刷新并检查结果。自动装载除了可以加载CI的组件外，也可以加载我们自己定义的组件，比如，在我们的应用中，总是要使用User_model这个组件，我们也可以自动装载这个我们自己的组件。在config/autoload.php中，修改代码：

1

$autoload['model'] = array('user_model');

然后在我们的控制器方法中就不需要显示的转载模型了。

1
2
3
4
5
6

public function index()
{
    //$this->load->model('user_model');
    $result = $this->user_model->get_users();
    print_r($result);
}

但是我个人是不推荐自动装载模型的，在方法中明确的装载模型是有利于代码的清晰度的，除非你有非常好的理由来自动装在模型。

把数据传送到视图

在控制器中我们可以装载不同的视图，在装载视图的同时，我们也可以把数据传送给视图，非常简单。

class User extends CI_Controller
{
    public function index()
    {
        $this->load->model('user_model');
        //把结果发在一个命名数组中
        $data['results'] = $this->user_model->get_users();
        //在装在视图的同时，把数据传送过去
        $this->load->view('user_index', $data);
    }
}
