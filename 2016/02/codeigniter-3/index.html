我们来完成一个完整的登录项目。

准备工作

我们不会从头创建我们的样式，我们使用流行的CSS框架Bootstrap来进行构建。下载bootstrap，然后在项目中新建一个目录，目录的名字叫做public可能是一个好的选择。在public下面，新建文件夹css fonts js，参考下面的图片，别忘了必备的jQuery。

创建模板

我们不想每个页面都从头构建，最佳的方式是创建模板。创建views\layouts目录。

在模板文件中如何引入css和js文件呢？路径是什么？我们可以使用CI提供的base_url()函数来获取项目的URL，当然这个值你也可以在config.php中进行修改。引入css类似这样的语句：

1

<link rel="stylesheet" href="<?=base_url()?>public/css/bootstrap.min.css">

base_url()函数返回的结果带有/路径，所以在public之前不要在添加/，以免画蛇添足。

这个函数不是马上就能使用的，它是CI提供的URL辅助功能，需要在autoload.php中开启这个支持。

1

$autoload['helper'] = array('url');

侧边栏

在侧边栏我们想显示登录窗口，这就涉及到了CI的表单控制功能，所以我们要在autoload.php中开启我们的表单辅助功能。

1

$autoload['helper'] = array('url', 'form');

表单数据验证

CI提供了表单验证的功能，帮助我们来进行数据的验证。首先，要在autoload.php中装载表单验证

1

$autoload['libraries'] = array('database', 'form_validation');

下面我们就可以修改User.php中的login方法，让它支持验证了。

1
2
3
4

6
7

9

public function login()
{
    $this->form_validation->set_rules('name', '用户名', 'trim|required|min_length[3]');
    $this->form_validation->set_rules('password', '密码', 'trim|required|min_length[3]');

    if ($this->form_validation->run() == FALSE) {
        print_r(validation_errors());
    }
}

上面的rules是CI提供的验证规则，trim是去掉输入的空格，required是必须提供输入，min_length是最小的输入长度，实际上CI提供的rules非常多，在CI的类库参考-表单验证类中可以找到全部的规则。你可以尝试着什么也不输入直接提交，或者输入一个自负的情况下提交。

上面的处理有一个问题，输出的错误信息是英文，我们不能指望我们的访问者读懂英语，毕竟我们说中文。那要怎么处理呢？这就涉及到了CI应用的语言问题。解决这个有几种方案。

第一，在application\config\config.php中，我们可以把$config['language'] = 'english';修改为chinese表示我们要说中文。如果现在你在重新提交表单，你会发现CI出现了错误，错误信息是找不到语言文件 language/chinese/form_validation_lang.php。这个文件我们怎么创建呢？我们复制system/language/english/form_validation-lang.php到目录application/language/chinese/下，什么，没有这个目录？你自己创建一个就完了。我们修改一个提示坐下测试

1

$lang['form_validation_required']		= '{field} 必须输入';

现在表单里面什么也不写，直接提交就看到中文的错误提示。

第二种方法，就是我们只需要几个中文的错误信息，没必要向上一种方法那么复杂，而且有些错误信息要单独的提示，怎么办？我们可以直接在可能输出错误信息的方法里面提供我们自己的错误说明。

public function login()
{
    $this->form_validation->set_rules('name', '用户名', 'trim|required|min_length[3]', [
        'required' => '你不写用户名我知道你是谁',
        'min_length' => '没哟这么短的名字'
    ]);
    $this->form_validation->set_rules('password', '密码', 'trim|required|min_length[3]');

    if ($this->form_validation->run() == FALSE) {
        print_r(validation_errors());
    }
}

也就是我们直接在规则里面添加我们的错误信息即可。你愿意用哪种方法你自己随意吧。

获取到了错误信息，我们不能直接这么粗暴的显示出来，正常的情况是我们返回登录页面然后在上面显示错误信息。但这就涉及到了跳转，也就是从User控制器跳转到Home控制器，然后传送我们的错误信息，我们需要在autoload.php中开启session。

1

$autoload['libraries'] = array('database', 'form_validation', 'session');

在CI中可以使用session中的flashdata作为一次性的输出信息，也就是输出一次，下次请求就没有了。

public function login()
{
    $this->form_validation->set_rules('name', '用户名', 'trim|required|min_length[3]', [
        'required' => '你不写用户名我知道你是谁',
        'min_length' => '没哟这么短的名字'
    ]);
    $this->form_validation->set_rules('password', '密码', 'trim|required|min_length[3]');

    if ($this->form_validation->run() == FALSE) {
        $data['errors'] = validation_errors();
        $this->session->set_flashdata($data);
        redirect('home');
    }
}
