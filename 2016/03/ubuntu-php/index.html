设置共享文件夹

  1. 在虚拟机设置中增加共享文件夹
  2. 正常启动虚拟机
  3. 选择device->Insert Guest Addtions CD Images
  4. 挂载光盘
1

sudo mount /dev/cdrom /media/cdrom/
  1. 安装必要软件
1

sudo apt-get install gcc make
  1. 安装增强工具
1

sudo /media/cdrom/VBoxLinuxAdditions.run
  1. 挂载共享文件夹
1
2
3

cd ~
mkdir host
sudo mount -t vboxsf -o uid=$UID,gid=$(id -g) xxxxx(共享名称) host

(可选）设置PHPStorm/WebStorm开发

  1. 修改权限
1
2

sudo chown 用户名:用户组 /var/www/html
sudo chown 用户名:用户组 /var/www/html/*
  1. 启动PHPStorm/， 选择 Create New Project form Existing Files，然后选择 Web server is on remote host, files are accessible via FTP/SFTP/FTPS，下一步后，设置项目名称和本地存储位置，在Specify parameters for a new server 中选择sftp，并设置参数，主机、用户名、口令，然后 Test SFTP connection，测试成功后选择root path，这里是/var/www/html。
  2. 设定完成后，在phpstorm/webstorm 中设置：Upload changed files automatically to the default server: On explicit save action(command+s)，你可以自行选择。
  3. 测试吧。
