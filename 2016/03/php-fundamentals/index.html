在HTML h1后面增加一个PHP的输出语句，

1

<?php echo 'Hello, World'; ?>

在浏览器中查看结果。对服务器来说，所有的HTML标记会原封不动的发送到客户端，但是一旦遇到了<?php的 开始标记，就会交给PHP处理程序进行处理，然后将结果发送回浏览器。在浏览器中查看源代码，我们只会看见 PHP的处理结果，而不会看见php的语句。

对php来说，我们也可以使用print来进行输出，不过使用echo在php的世界中更常用一些。字符串可以使用 单引号或者双引号。

2
3

php中的变量使用$开始作为变量开始。 我们来看一下单引号和双引号之间的区别。

1
2
3

$name = 'zhangjinglin';

echo 'Hello, $name'; //Hello, $name

对php来说，双引号字符串中的变量是可以被解析的，单引号中的变量不被解析，直接原样输出。对于 不含变量的字符串来说，单双引号没有区别。

出了可以使用include也可以使用require来进行文件包含，两者的区别是，include如果没有找到文件 会发出警告并继续执行，而require会出现错误并停止执行。 还有一个require_once能够保证仅仅包含一次文件，即使你写了多个。比如你写了一个类B文件，依赖 另外一个类A，有可能其他的类C也依赖类A，当同时使用类B和类C就可能引入两次类A，所以使用require_once 就是一个好的选择。

我们来实现上面的函数

 1
 2

10

function array_pluck($toPluck, $arr)
{
    $ret = [];
    foreach($arr as $item) {
        $ret[] = $item[$toPluck];
    }

    return $ret;

}

我们现在利用php提供的array_map来实现我们上面的函数。

1
2
3
4
5
6

function array_pluck($toPluck, $arr)
{
    return array_map(function($item) {
        return $item[$toPluck];
    }, $arr);
}

上面的函数将导致错误，说$toPluck是一个没有定义的变量。在php中，变量的作用域仅仅在函数中 ，这意味着我们的array_map的调用函数中是不存在$toPluck这个变量的。为了使用函数外部的变量， 我们需要修改代码

1
2
3
4
5
6

function array_pluck($toPluck, $arr)
{
    return array_map(function($item) use($toPluck) {
        return $item[$toPluck];
    }, $arr);
}

上面代码中的use($toPluck)将函数外部的变量带入到了函数中。
