什么东东?

Tesseract.js 是一个Tesseract OCR引擎的javascript移植。这个库支持超过60种语言（包括中文），能够自动识别文本方向和笔迹检测。 可以运行在浏览器和NodeJS中。

怎么安装？

  • 浏览器
1
2

<script src='https://cdn.rawgit.com/naptha/tesseract.js/1.0.10/dist/tesseract.js'>
</script>
  • NodeJS
1
2
3

yarn add tesseract.js
//or
npm install tesseract.js --save

基础案例

新建一个项目，进行初始化

1
2
3
4
5

mkdir tesseract-demo
cd tesseract-demo
yarn init
yarn add tesseract.js
touch index.js

我们先来找一个中文页面，进行截图，将图像放置到项目目录中。我截取了这样一个图像。

下面来进行index.js的代码：

1
2
3
4
5

const Tesseract = require('tesseract.js')

Tesseract.recognize('./image.png', 'chi_sim') //第二个参数表示语言，缺省的话为eng，英文
  .progress((p) => console.log('progress', p))
  .then((result) => console.log('result', result))

运行：

1

node index.js

首次运行会先下载chi_sim.traineddata识别库，然后进行识别，需要等待一下，第二次则不需要下载了。
